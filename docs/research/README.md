# Research notes

Dated, read-only research behind the console and the backend's API: how ACM (`acm.md`), Keycloak
Organizations (`keycloak.md`), the models and MaaS stack (`models-maas.md`) and the hub's
observability (`observability.md`) behave, and the backend's conventions next to OSAC's
(`backend-conventions.md`). Each records what was found when it was written, with its sources.

They were written for the console's former draft proto and fake backend, so they cite paths that
no longer exist: `mock/proto`, `mock/fixtures`, `mock/areas`, `bff/internal/fakebackend`,
`bff/internal/protodrift` and `docs/plan/work-breakdown.md` (git history has them). The contract
is now the backend's own proto (`docs/connect.md`), and where a note and the backend disagree,
the backend wins.
